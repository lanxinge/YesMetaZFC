## 1. 收集的真正目标

[collection-cover.lean](../research/ChoiceFreeZF/collection-cover.lean) 核验了一个精确归约。对小索引 `I`，小图收集结论

```text
∃ C, ∀ i, ∃ y∈C, R(i,y)
```

等价于存在一个小指标族 `J`、满射 `q : J → I` 和实际原始图族 `F : J → WF_graph`，使 `R(q j, mk(F j))` 对所有 `j` 成立。一个输入可以有多个见证；不需要选择函数。

正向只对单个已有收集集取一次呈现，再使用该图全部根孩子，通过所有满足 `R` 的输入—孩子关系边组成覆盖。反向直接作根并合。`cr_sg_iff` 的证明没有逐输入选代表或选关系见证。`cr_generic_iff` 还区分了单点存在与泛型阶段的统一覆盖。

对布尔值语义，原 ZF 模式要求的目标更弱：

```text
(∀ x∈a, ⋁ y, R(x,y)) ≤ ⋁ c, (∀ x∈a, ⋁ y∈c, R(x,y))
```

它不要求元层存在一个 `c` 达到整个左侧真值。对稳定命题代数，右侧是双重否定存在。不能把它改成正存在、最大值原则或逐输入选择函数。

[semantics-stable.lean](../research/ChoiceFreeZF/semantics-stable.lean) 的两点实例精确说明这个区别：两个稳定真值 `¬P` 与 `¬¬P` 的上确界总为顶，但元层存在一个达到顶的分支，等价于弱排中律 `¬P ∨ ¬¬P`。这是关于错误的通用见证提取步骤的诊断，不是对完整名称混合或 ZF 模型的不可能性证明。

## 2. 描述完备性可以沿 W 型保留

[semantics-description.lean](../research/ChoiceFreeZF/semantics-description.lean) 定义 `D(A)` 为描述 `A` 中单个值的非空单元素谓词。谓词是实际数据，中心的存在性保留在 `Prop`。

本轮核验了：若标签类型 `A` 有实际的描述消去 `D(A) → A`，则任意分支族 `B` 的 W 型也有描述消去。

证明没有先将一族子描述提升为一族代表。它先描述根标签，再描述每个子树；在描述之间定义下降关系。在 `Prop` 内借唯一中心和原 W 归纳证明该关系良基，最后用良基递归重建整棵树。`WT.retract_pure` 与 `WT.retract_spec` 验证重建的正确性。

实际实例取标签 `D(Type u)`、点 `D(Σ T : Type u, T)`，分支是点到标签映射的纤维。得到 `Tree : Type (u+1)` 及实际 `tree_desc`。在该载体上，`replacement`、`replacement_mem` 实现按原类型等号唯一的关系替换；`identity_image` 是具体消费者。

**这个树还不是外延集合。** `singleton_bool` 与 `singleton_unit` 分别用两个重复分支和一个分支表示同一个成员。`singleton_same_members` 与 `singleton_distinct` 同时证明成员相同、树却不同。因此原等号版本的替换不能冒充 ZF 的替换；将等号改成双模拟后，唯一性不再是原类型等号，不能直接交给 `tree_desc`。

还须区分正的唯一存在与双重否定的唯一存在。当前 `D` 处理前者；后者需要另外证明合适的稳定描述闭包，不能自动推广上述 W 证明，因为可访问性并不默认稳定。

## 3. 观察载体绕开了直接选择呈现

[collection-church.lean](../research/ChoiceFreeZF/collection-church.lean) 取所有小观察代数的依赖积。每个观察包含小状态类型、实际唯一描述结构和一个幂集代数。对只附带小性存在证书的谓词，直接把其每个观察下的像交给该代数；这个 `sup` 不读取选定呈现。

以正归纳闭包得到实际载体 `V`。已有 `v_desc` 和 `v_sup`：既能消去唯一描述，也能直接合成小谓词。记录观察在第二坐标保存一步输入像；`sup_iff_profiles` 把合成值相等精确归约为每个观察下成员像相等。`pi_obs`、`joint_profile` 将任意实际给定的小观察族合并为一次观察。

更强的结果是小图观察。对任意给定小良基图 `G`，状态取 `G.Domain → Prop`，代数检验两侧孩子的匹配。`graph_code_unique` 证明这个观察能识别该图的编码；`graph_closed` 将以该编码为目标的观察闭包反射回实际成员。

`graph_code_iff`、`sg_code_injective`、`sg_code_mem` 给出原全部 `SG_set` 到新 `V` 的忠实嵌入，保留并反射成员关系，且旧像向下封闭。这是实际的全小图实例，不是只测有限例子。没有证明这个嵌入满射，也不要求新架构必须退回旧图呈现。

一般生成值的联合可分离性仍缺失。现有小积只能处理一个已经给定的小观察族，不能直接合并位于更高 universe 的全部观察。将观察的相等剖面编码到小域，仍没有给出每个剖面的规范代数或封闭状态域。

## 4. 稳定观察提供经典逻辑与外延性

[semantics-church-stable.lean](../research/ChoiceFreeZF/semantics-church-stable.lean) 是单独核验的稳定变体。真值为稳定命题 `SP`；观察等号稳定，代数消费稳定像。生成性用 `Prop` 中最小的稳定闭包表达，`gen_shape` 已证明生成值具有双重否定存在的呈现。

成员关系由各观察的记录像定义。`extensionality` 证明成员范围相同就得到载体等号，**不需要先证明 `sup` 对原小谓词注入**。`pair_mem` 给出精确成员律 `Mem x (pair a b) ↔ ¬¬(x=a ∨ x=b)`，即 `SP` 的析取。

`algebra` 是实际 `CB_alg SP`；`structure_model`、`structure_laws` 和 `structure_rules` 接回仓库原集合论语言与原 Hilbert 六规则。另有空对象、单元素对象及它们不同的证明，故非平凡性不是假设。

当前最值得继续攻的是**并集的实际构造与完整成员律**。不能只写一个逐观察的二层像并集：还要证明输出属于生成载体，并证明它等于原语义的 `∃ y, x∈y ∧ y∈a`。逐观察分别找到中间集合，不等于同一个中间集合在全部观察下成立。分离还须解决观察闭包与公式过滤是否相容；幂集不能预设该问题已解决。

这里公理本身的最弱目标保持为：

```text
∀ G : V, ¬¬∃ U : V, ∀ x : V,
  Mem x U ↔ ¬¬∃ y : V, Mem x y ∧ Mem y G
```

直接构造一个具体 `U` 只是可能的证明方法，不把正存在或全局并集函数当成新模型的必要条件。若采用上面的逐观察候选，则生成性和成员律是该具体方法必须补齐的两项义务。

两种观察版本不能机械合并。旧小图能表示 `a_P={∅ | P}` 与 `1={∅}`，且 `a_P=1` 恰好等价于 `P`。若整个旧小图按原等号单射进入一个等号稳定的载体，就能从 `¬¬P` 推出 `P`，进而得到元层排中律。普通观察的忠实嵌入与稳定观察的稳定等号因此不能同时作为无选择的原等号接口继承。这个限制允许改变对应关系或等号语义，不排除稳定观察路线本身。

## 5. 条件秩与局部对角界

[foundations-graph-rank.lean](../research/ChoiceFreeZF/foundations-graph-rank.lean) 将图边改成非空传递闭包，节点域不变。双模拟沿有限路径传递，故直接下降为 `fg_set_rank : SG_set → SG_set`，无需代表元选择。

已证精确秩递归式、成员严格下降、秩及其成员传递、传递且成员传递的集合是不动点、秩算子幂等。这里保留了条件信息，未声称元层的经典序数三歧性。

固定小域 `A` 后，所有 `A` 上的良基有根关系仍构成小类型。`fg_bound A` 直接并合它们的全部秩，构造实际对象 `H(A)`。每个这样的秩都属于 `H(A)`，而 `H(A)` 不等于其中任一个秩，否则自属。该局部对角界没有预设界，也没有选代表；但还不是具有全部传统映射规格的经典 Hartogs 数。

[foundations-rank.lean](../research/ChoiceFreeZF/foundations-rank.lean) 给出两点检验：边恰在 `P` 成立时存在。固定自然数上界始终有效，但存在满足精确秩像式的自然数秩，恰好等价于 `P∨¬P`。同一个图却始终有条件集合值精确秩 `{∅ | P}`。这排除的是未经证明的线性规范化，不排除所有秩方法。

[root-universe.lean](../research/ChoiceFreeZF/root-universe.lean) 还直接构造了收纳全部低层图集合的高层容器，并证明该容器不能降回低层。它没有排除某个具体公式的见证族存在低层界。

## 文献与本次推导的关系

本次构造均由 Lean 证明核验；未宣称这些结果在文献中首次出现。文献用于找出应审计的步骤，没有当作额外模型前提。

- [Gambino–Aczel](https://www.cs.le.ac.uk/people/ngambino/Publications/gambino-aczel.pdf) 的逻辑丰富类型论解释需要相应收集规则；不能直接从 CZF 解释得到本项目的完整 ZF。
- [Streicher 的三页说明](https://www2.mathematik.tu-darmstadt.de/~streicher/CIZF/rmczfnp.pdf) 明确区分类型构造与附加的小覆盖/收集原则。
- [Shulman，§7](https://arxiv.org/pdf/1004.3802)：泛型元素给出栈收集，但无限覆盖拼合和 autology 的相应结果仍使用背景 IZF。它不能直接解决当前 Lean 的小性问题。
- [Swan](https://arxiv.org/abs/2005.14240) 在已有 ZF 中构造一类无选择 QW 型。其秩界方法值得借鉴，但不能借元层 ZF 来构造待证的 ZF 模型。
- [Matthews，§12](https://arxiv.org/abs/2307.13563) 的 Krivine 收集验证先使用背景收集得到见证界；经典实现码本身没有产生这个界。
