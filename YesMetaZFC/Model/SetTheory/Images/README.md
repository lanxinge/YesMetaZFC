# 成员满映射与图像运输

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [BinaryImage](BinaryImage.lean) | 成员满嵌入保持规范二值编码 |
| [GameCanonicalImage](GameCanonicalImage.lean) | 同实数的成员满模型之间的决定性绝对性；规范局面编号下的策略实数运输 |
| [NaturalBasisImage](NaturalBasisImage.lean) | 规范常零及后继图的有界读取与成员满保持 |
| [OrdinalSequenceImage](OrdinalSequenceImage.lean) | 规范序数配对沿成员满嵌入保持；内部有限序列的规范代码沿成员满嵌入保持 |
| [RelationCodeImage](RelationCodeImage.lean) | 成员满嵌入反射良序并保持实际坍塌值域；同一良序实数的解码与原序型回收 |
