# 反射、坍塌与模型证书

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [RankAbsolute](RankAbsolute.lean) | 实际极限秩模型中的累积层绝对性 |
| [RankLargest](RankLargest.lean) | 最大序数对应的前一秩层 |
| [RankSatisfaction](RankSatisfaction.lean) | Vν 的满足关系在 V(ν+1) 中的单一公式 |
| [RankSkolem](RankSkolem.lean) | 实际内部司寇伦函数与最小闭包；极限秩初段中的实际小 Skolem 壳 |
| [ReflectedRankReals](ReflectedRankReals.lean) | 反坍塌两侧的真实有限求值表；反射壳固定全部内部有限程序；反坍塌在内部集合结构上的完整初等限制；原返回秩层包含测试壳的全部实数集 |
| [ReflectedSeed](ReflectedSeed.lean) | 有限反射下固定可数传递种子的测试壳；反射壳包含全部背景内部有限函数；反射壳中的可数模型与原函数图；弱测试壳回拉同一完整局面编号 |
| [RelativeCountable](RelativeCountable.lean) | 相对秩层中的源内编号与可数图 |
| [SkolemImage](SkolemImage.lean) | 原司寇伦选择图在成员满扩张中保持 |
| [SkolemSyntax](SkolemSyntax.lean) | 内部司寇伦选择的实际公式 |
| [SkolemWitnessTree](SkolemWitnessTree.lean) | 实际司寇伦见证树及其可数初等分支 |
| [TransitiveSequence](TransitiveSequence.lean) | 传递源的原始序数、自然数与函数解释；传递源中的基数和共尾序列；任意传递集合中的原函数公式；共尾公式在传递集合中的精确读取 |
| [ZfcTransfer](ZfcTransfer.lean) | 背景内部的完整 ZFC 模型证书；完整内部 ZFC 证书向成员满外层的保持；内部 ZFC 证书的原语言解码；不可达秩段上的实际内部 ZFC 证书 |
