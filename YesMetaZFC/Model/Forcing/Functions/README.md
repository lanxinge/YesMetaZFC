# Functions

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [CheckCompare](CheckCompare.lean) | 检查子集名字的逐成员求值；同一个检查子集名字的双向实数解释 |
| [Coordinate](Coordinate.lean) | 泛型条件中指定坐标的并图 |
| [Cover](Cover.lean) | 名称在旧集合中的覆盖证书 |
| [Generic](Generic.lean) | 部分函数条件的泛型函数名称 |
| [Surjection](Surjection.lean) | 函数名称的旧值判定；满射名字的旧输出见证 |
| [ValueIsomorphism](ValueIsomorphism.lean) | 实际函数名称的原公式证书；实际单射名称的原公式证书；被迫函数、单射与传递容器的局部规则；完整函数解释的原模型名字证书 |
