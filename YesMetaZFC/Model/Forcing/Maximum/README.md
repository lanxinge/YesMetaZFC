# Maximum

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [Bounded](Bounded.lean) | 按内部序数枚举选择名称；内部名称的统一成员见证；原公式的内部最大值原理；固定条件上的库内见证选择 |
| [Normal](Normal.lean) | 全局力迫等号类的规范名称构造式；任意内部名称的确定规范代表 |
| [Unique](Unique.lean) | 原 ZF 中的唯一见证名称装配 |
| [UniqueRules](UniqueRules.lean) | 输入名称的唯一最小闭名称库；任意内部预序上的名称混合；混合闭合的确定名称库；在固定名称库内修补局部见证 |
| [WitnessPool](WitnessPool.lean) | 原 ZF 中的有界局部见证池 |
