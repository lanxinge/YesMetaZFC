# 地对象与背景解释

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [BackgroundExtension](BackgroundExtension.lean) | 泛型名字商的实际背景集合编码；原名字商在背景模型中的传递呈示；背景传递呈示逐点还原地模型 |
| [CheckPool](CheckPool.lean) | 成员满嵌入反射有序对、后继和条件序；规范检查名字在成员满嵌入下的双向绝对性；大泛型沿成员满地包含回读为原泛型；保持地参数的中间同构运输同一个第二步滤子 |
| [Collapse](Collapse.lean) | 规范名称的地模型嵌入与有界结构保持；与基条件无关的地模型值；旧部分函数图的成员满嵌入保持；沿同一地参数识别的完整函数图解释 |
| [DenseEnumeration](DenseEnumeration.lean) | 每个可数阶段出生的全部稠密任务都有实际编号 |
| [FilterSet](FilterSet.lean) | 地模型自同构及其滤子回拉在扩张中的同一解释；地条件自同构的滤子回拉是背景中的实际集合 |
| [GenericTree](GenericTree.lean) | 有限闭包检查沿成员满嵌入保持；原闭包树在扩张中的精确节点识别；见证树及其新枝的内部初等性；原稠密任务树在扩张中的精确保持 |
| [Graph](Graph.lean) | 地模型对象的无权小图呈现 |
| [NaturalRead](NaturalRead.lean) | 规范自然数图的完整读取恢复背景中的同一基底 |
| [Ordinals](Ordinals.lean) | 旧集合嵌入下的序数反射与共尾集保持；名称支撑的内部秩图与求值图；泛型扩张不增加序数 |
| [PowerGeneric](PowerGeneric.lean) | 原幂集可数证书产生实际地泛型 |
| [ProductBlock](ProductBlock.lean) | 原坐标块及逐坐标加强的成员满绝对性 |
| [ProductCoordinates](ProductCoordinates.lean) | 原泛型的实际坐标滤子列与全部有限前缀 |
| [ProductProjection](ProductProjection.lean) | 以原载体为稠密参数域的背景泛型公式；原模型全部稠密集族的背景编码与初等运输；原模型参数域的背景泛型性向外保持；实际背景泛型集合的有限前缀投影 |
| [QueryTree](QueryTree.lean) | 联合字母、坐标图形与登记检查的保持；同一联合有限树向强迫扩张保持；查询字母及实际复合投影向同一扩张保持；原源名字判值及全部有限检查在成员满扩张中保持 |
| [RankRealNames](RankRealNames.lean) | 检查子集名字在两侧泛型扩张中的实际实数值；原秩模型的实际名字覆盖背景泛型扩张的所有实数 |
| [RealCodeImage](RealCodeImage.lean) | 实数名字见证的背景公式；初等名字提升保持同一个完整实数图；原名字解释的完整背景图留在反射壳内；同一完整背景函数名字证书的成员满运输 |
| [RealGround](RealGround.lean) | 完整函数图读取与成员满像的识别；原地模型实数在指定泛型中的完整名字证书 |
| [RealValue](RealValue.lean) | 有限集合模型泛型扩张的每个实数都有实际背景图 |
| [SourceExtension](SourceExtension.lean) | 大扩张内原源模型、实际泛型集合及指定名字的同一呈示 |
| [SubsetOrder](SubsetOrder.lean) | 反向包含条件序在成员满扩张中的精确解释 |
| [TreeShift](TreeShift.lean) | 成员满嵌入保持全部内部有限列；规范嵌入下内部语法码的绝对性；新无限列的每个内部有限前缀都有真实地原像；地模型有限合法走法的双向保持 |
