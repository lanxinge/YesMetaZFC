# Projective

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [CountableBase](CountableBase.lean) | 内部射影点类；全部内部射影层的实际集合图；射影层次的内部单调性；单个内部射影码 |
| [Iteration](Iteration.lean) | 沿内部 ω 的射影求值 |
| [Section](Section.lean) | 实数参数截面及其与补、投影的交换 |
| [Strict](Strict.lean) | 全部内部层号上的可数并交矩阵；指定层号与极性的内部射影码族；Σ、Π 层实际码族的同层可数并交；相对射影点类的补对偶 |
