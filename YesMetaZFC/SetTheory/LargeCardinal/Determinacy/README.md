# 查询树与决定性

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [LReal](LReal.lean) | 真类 Woodin 推出 L(ℝ) 满足 AD |
| [QueryTreeTruth](QueryTreeTruth.lean) | 任意正负树分支在真实 L(ℝ) 中给出同一查询点的见证 |
| [TwinTreeOutward](TwinTreeOutward.lean) | 双树覆盖反射中原源模型的十二个实际参数；小坍缩双树覆盖的完整有限反射输入；原题设中的统一小坍缩力迫覆盖；原双树资料的实际有限输入工厂 |
| [TwinTreeRank](TwinTreeRank.lean) | 双树胜策的反方反例树秩 |
| [TwinTreeSyntax](TwinTreeSyntax.lean) | 同一坍缩扩张中的双树二择一；同一次小坍缩扩张中的原正负树穷尽；双树论证的原一阶公式 |
