# 内部类型与弹性

本目录按依赖次序组织相关定义、构造与证明。公开声明保留原命名空间，调用时直接导入下列模块。

| 模块 | 数学内容 |
| --- | --- |
| [CandidateModel](CandidateModel.lean) | 原生模型之间的旧查询运输；原生旧轮语言在共同层中的完整像；原生模型间同一候选的共同层运输 |
| [ContinueAbsolute](ContinueAbsolute.lean) | 相对类型像证书的实际读取；在给定所属模型内还原反射的单步证书；同一次继续选择在所属模型中的完整证书 |
| [ContinueRealizeSyntax](ContinueRealizeSyntax.lean) | 原子类型查询的低层实现句子 |
| [ContinueScope](ContinueScope.lean) | 真实继续输入中两份类型的极限秩界 |
| [ElasticClauses](ElasticClauses.lean) | 定义 3.13 的最大序数与不可达性查询 |
| [ElasticDomain](ElasticDomain.lean) | 只从两条定义域查询读取实际前驱 |
| [ElasticNumericTransfer](ElasticNumericTransfer.lean) | Neeman 定义 3.13：原类型的弹性；编码表中的实际弹性关系；四条弹性查询的统一读取公式；弹性程序的低参数正确性句子 |
| [ElasticQuery](ElasticQuery.lean) | 弹性查询的合法名字列；指定扩展器的实际类型伸展；类型伸展的有界矩阵；有界矩阵与原实际类型伸展的等价 |
| [ImageSyntax](ImageSyntax.lean) | 类型像的同一扩展器证书 |
| [MinusStretch](MinusStretch.lean) | 前驱类型与同一实际扩展器的伸展交换 |
| [OneStep](OneStep.lean) | 从可实现弹性类型自动提取伸展数据；Neeman 引理 3.23：弹性类型的一步伸展 |
| [OneStepDropImage](OneStepDropImage.lean) | 一步伸展中的实际像子类型；继续分支的一步伸展反射句子；删除末位的一步伸展在同一超幂中的实际像 |
| [PoolRead](PoolRead.lean) | 有限闭源中的完整查询域 |
| [RawSubtype](RawSubtype.lean) | 固定原施加的完整代表池输运 subtype |
| [Renewal](Renewal.lean) | 局部不可分辨点提升同一完整类型的原前缀；迭代轮中的弹性回答与一步扩展器 |
